# 技术笔记规范设计文档

## 项目概述
为个人技术笔记本创建结构化的记录规范，支持K8s、AI/LLM、存储系统等技术领域的快速故障排除、详细解决方案文档和个人学习记录。

## 设计目标
1. **快速故障排除**：能够迅速定位和解决常见问题
2. **详细解决方案**：记录复杂问题的完整解决过程
3. **个人学习记录**：积累技术知识和最佳实践
4. **AI辅助**：通过Claude AI实现智能模板应用和内容管理

## 核心设计原则
- **结构化**：使用统一的模板确保信息完整性
- **可检索**：通过技术关键词标签实现快速查找
- **AI友好**：设计便于AI理解和处理的格式
- **中文优先**：所有内容使用中文记录

## 文件组织架构

### 目录结构
```
notebook/
├── CLAUDE.md                    # 规范文件（本设计的实现）
├── troubleshooting/             # 故障排除笔记
│   ├── k8s/                     # Kubernetes相关故障
│   ├── ai-llm/                  # AI/LLM相关故障
│   ├── storage/                 # 存储系统故障
│   └── network/                 # 网络相关故障
├── knowledge/                   # 知识积累笔记
│   ├── concepts/                # 技术概念
│   ├── configurations/          # 配置指南
│   └── best-practices/          # 最佳实践
├── templates/                   # 模板文件
│   ├── troubleshooting.md       # 故障排除模板
│   └── knowledge.md             # 知识积累模板
└── index/                       # 自动生成索引（AI维护）
    ├── tags-index.md            # 标签索引
    └── recent-notes.md          # 最近笔记
```

### 文件命名规范
- **故障排除**: `YYYY-MM-DD-[技术领域]-[问题关键词].md`
- **知识积累**: `[技术领域]-[知识点]-guide.md` 或 `[技术领域]-[知识点]-concept.md`

示例：
- `2026-04-01-k8s-pod-crashloopbackoff.md`
- `2026-04-01-vllm-gpu-memory-oom.md`
- `k8s-networking-service-mesh-guide.md`

## AI辅助功能设计

### 自动模板应用
AI应该能够：
1. 识别用户描述的问题类型（故障排除 vs 知识积累）
2. 自动选择合适的模板
3. 根据用户输入填充模板字段
4. 建议合适的文件名和标签

### 智能标签建议
AI应该能够：
1. 分析笔记内容自动建议相关标签
2. 保持标签的一致性
3. 建议相关的现有笔记

### 内容关联
AI应该能够：
1. 识别相关的历史笔记
2. 提供交叉引用建议
3. 维护知识图谱
